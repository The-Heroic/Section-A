Content Alignment Demonstration (No CSS)

Paragraph Alignment

This paragraph uses the **left** alignment, which is the default for most text and generally the best for readability.

This paragraph uses the **center** alignment attribute. This was often used for titles or short messages.

This paragraph uses the **right** alignment attribute.

This paragraph demonstrates the **justify** alignment. Justified text stretches the lines to align with both the left and right margins. In older browsers, the effect might be less precise than with modern CSS. For this effect to be visible, the paragraph should contain enough text to wrap across multiple lines. This is a common requirement when trying to replicate newspaper layouts.

Image Alignment

This paragraph contains an image that is aligned to the **left** using the `align="left"` attribute on the `` tag. The text wraps around the image, which was the standard way to achieve a text-wrap layout without CSS. The `hspace` and `vspace` attributes are used here to add horizontal and vertical space (margin) around the image, preventing the text from touching it.


Here is another paragraph with an image that is aligned to the **right** using `align="right"`. Note that the subsequent paragraph text will continue to flow around the image until the image's height is exceeded.
